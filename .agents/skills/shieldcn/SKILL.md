# shieldcn — GitHub README Badge Generator

**shieldcn** (by `jal-co/shieldcn`) generates minimalist, high-contrast, shadcn-inspired badges for project documentation and GitHub `README.md` files.

## Badge Styling Specifications

- **Background Color**: `#09090B` (Zinc-950 dark background)
- **Style**: `for-the-badge` or `flat-square`
- **Text Color**: `#FAFAFA`
- **Logos**: Official SVG icons via SimpleIcons with colored brand accent fills
