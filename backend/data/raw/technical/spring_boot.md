# Spring Boot

## Overview

Spring Boot is a Java framework for building production-oriented applications with conventions and auto-configuration that reduce setup.

## Core Interview Areas

- Spring versus Spring Boot
- Inversion of Control
- Dependency Injection
- Bean lifecycle
- Component scanning
- Auto-configuration
- Starter dependencies
- REST APIs
- Validation
- Exception handling
- Spring Data
- Spring Security
- Transactions
- Profiles and configuration

## Dependency Injection

Dependency Injection means an object's dependencies are supplied to it rather than the object constructing those dependencies itself.

## REST APIs

Interview preparation should cover:

- Resource-oriented URL design
- HTTP methods
- HTTP status codes
- Request validation
- Exception handling
- Pagination
- Versioning
- Idempotency

## Production Concerns

Prepare to explain:

- logging
- configuration management
- security
- database transactions
- monitoring
- testing
- deployment

## Interview Framework

For each Spring concept:

1. Define it.
2. Explain how it works internally.
3. Explain when to use it.
4. Explain common mistakes.
5. Give a production example.
