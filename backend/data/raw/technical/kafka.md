# Apache Kafka

## Overview

Kafka is a distributed event-streaming platform designed for high-throughput, durable event processing.

## Core Concepts

- Producer
- Consumer
- Topic
- Partition
- Offset
- Consumer group
- Broker
- Replication

## Kafka vs RabbitMQ

Kafka is commonly used for high-throughput event streaming, durable logs, replay, multiple consumers, and stream processing.

RabbitMQ is commonly used for traditional task queuing, routing, and worker patterns.

## Interview Areas

- Partitioning
- Ordering
- Consumer groups
- Offset management
- Replication
- Delivery semantics
- Retention
- Idempotent consumers
- Failure handling

- How would you design an order-event pipeline?
