# Java

## Overview

Java is a general-purpose, object-oriented programming language widely used for backend and enterprise application development.

- OOP
- String and String Pool
- Collections
- Exception Handling

- Memory management
- HashMap internals

## Java 8+ Topics

### Lambda Expressions

Lambda expressions provide a concise way to represent behavior and are commonly used with functional interfaces.

### Functional Interfaces

A functional interface has exactly one abstract method and can be used as the target type of a lambda expression.

### Stream API

The Stream API supports declarative processing of collections using operations such as filter, map, sorted, and collect.

### Optional

Optional represents a value that may or may not be present and can reduce some forms of null-handling.
