# Career Compass AI — Upskilling Modules

## Purpose
Use these modules for learning-path recommendations based on:
- candidate skills
- target role
- required job skills
- skill gaps
- prerequisites
- career goals

## Module: TypeScript for JavaScript Developers
**Difficulty:** Beginner to Intermediate
**Estimated time:** 15–20 hours
**Prerequisites:** JavaScript fundamentals
**Technologies:** TypeScript, JavaScript, React, Node.js

### Learning Objectives
- Explain why TypeScript is used.
- Define types for variables, functions, objects, and arrays.
- Use interfaces and type aliases.
- Create generic functions and types.
- Apply utility types.
- Configure strict mode.

### Recommendation Criteria
Recommend when the target role requires TypeScript, React with TypeScript, or Node.js with TypeScript and the learner has JavaScript experience.

## Module: Docker and Containerization
**Difficulty:** Beginner to Intermediate
**Estimated time:** 10–15 hours
**Prerequisites:** Linux CLI, web application architecture, backend development
**Technologies:** Docker, Docker Compose

### Learning Objectives
- Explain containers versus VMs.
- Build Docker images.
- Use Docker Compose.
- Configure networking and volumes.
- Add health checks.

## Module: RAG and Vector Databases with LangChain
**Difficulty:** Intermediate
**Estimated time:** 20–25 hours
**Prerequisites:** Python fundamentals, basic LLM API usage, embeddings concepts
**Technologies:** Python, LangChain, ChromaDB/Pinecone, FastAPI

### Learning Objectives
- Load and parse documents.
- Split documents into useful chunks.
- Store embeddings in vector stores.
- Use retrieval, hybrid search, reranking, and citations.
- Evaluate retrieval and generation.

## Module: Kubernetes Application Deployment
**Difficulty:** Intermediate
**Estimated time:** 25–30 hours
**Prerequisites:** Docker fundamentals, containerization, basic networking
**Technologies:** Kubernetes, Minikube

### Learning Objectives
- Understand Pods, Deployments, and Services.
- Use ConfigMaps and Secrets.
- Deploy multi-service applications.
- Configure Ingress and persistent storage.
