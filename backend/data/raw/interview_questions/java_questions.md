# Java Interview Questions

## Beginner
### Q1 — JDK vs JRE vs JVM
**Difficulty:** Beginner
**Expected concepts:** JVM, JRE, JDK.

### Q2 — `==` vs `equals()`
**Difficulty:** Beginner
**Expected concepts:** reference comparison, logical equality, Object.equals().

## Intermediate
### Q3 — Why is String immutable?
**Difficulty:** Intermediate
**Expected concepts:** string pool, security, thread safety, hashCode behavior.

### Q4 — How does HashMap work internally?
**Difficulty:** Intermediate
**Expected concepts:** hashCode, buckets, collisions, equals, treeification.

### Q5 — What is a functional interface?
**Difficulty:** Intermediate
**Expected concepts:** one abstract method, lambda compatibility, @FunctionalInterface.

## Advanced
### Q6 — Explain Java concurrency problems you have encountered in production.
**Difficulty:** Advanced
**Expected concepts:** race conditions, synchronization, visibility, locking, practical trade-offs.
