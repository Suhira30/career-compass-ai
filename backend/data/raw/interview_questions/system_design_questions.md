# System Design Interview Questions

## Beginner
### Q1 — Design a URL shortener.
**Difficulty:** Beginner
**Expected areas:** requirements, API, storage, ID generation, scaling.

## Intermediate
### Q2 — Design a notification system.
**Difficulty:** Intermediate
**Expected areas:** APIs, queues, workers, retries, idempotency, delivery status.

### Q3 — Design a URL or file service for high traffic.
**Difficulty:** Intermediate
**Expected areas:** load balancing, caching, database scaling, availability.

## Advanced
### Q4 — Design an event-driven order processing platform.
**Difficulty:** Advanced
**Expected areas:** Kafka, consumers, idempotency, consistency, failure recovery, observability.
