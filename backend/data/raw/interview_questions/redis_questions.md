# Redis Interview Questions

## Beginner
### Q1 — What is Redis and why is it fast?
**Difficulty:** Beginner
**Expected concepts:** in-memory storage, data structures, low-latency access.

## Intermediate
### Q2 — Explain cache-aside.
**Difficulty:** Intermediate
**Expected concepts:** cache hit, cache miss, database read, cache population.

### Q3 — What are cache invalidation challenges?
**Difficulty:** Intermediate
**Expected concepts:** stale data, TTL, invalidation strategies.

## Advanced
### Q4 — How would you prevent cache stampede?
**Difficulty:** Advanced
**Expected concepts:** locking, request coalescing, TTL jitter, warming.
