# Kafka Interview Questions

## Beginner
### Q1 — What is a Kafka topic?
**Difficulty:** Beginner
**Expected concepts:** logical event stream, partitions.

## Intermediate
### Q2 — What is a consumer group?
**Difficulty:** Intermediate
**Expected concepts:** consumer coordination, partition assignment, parallelism.

### Q3 — Kafka vs RabbitMQ?
**Difficulty:** Intermediate
**Expected concepts:** event streaming, task queues, throughput, replay, routing.

## Advanced
### Q4 — How do you handle duplicate Kafka messages?
**Difficulty:** Advanced
**Expected concepts:** idempotency, offsets, deduplication, transactional approaches.
