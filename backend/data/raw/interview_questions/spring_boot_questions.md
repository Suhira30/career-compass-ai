# Spring Boot Interview Questions

## Beginner
### Q1 — What is Spring Boot?
**Difficulty:** Beginner
**Expected concepts:** Spring ecosystem, auto-configuration, starters, embedded server.

### Q2 — Spring vs Spring Boot?
**Difficulty:** Beginner
**Expected concepts:** configuration, conventions, auto-configuration, starters.

## Intermediate
### Q3 — What is Dependency Injection?
**Difficulty:** Intermediate
**Expected concepts:** IoC, dependency management, constructor injection.

### Q4 — How does Spring Boot auto-configuration work?
**Difficulty:** Intermediate
**Expected concepts:** classpath conditions, configuration, beans.

### Q5 — How do you handle validation and exceptions in a REST API?
**Difficulty:** Intermediate
**Expected concepts:** validation, exception handlers, HTTP status codes, consistent error responses.
